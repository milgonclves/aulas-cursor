# Primeiro Projeto

Projeto de site desenvolvido com Next.js, React, TypeScript e Tailwind CSS. A aplicação inclui páginas e componentes para apresentação de produtos e serviços.

## Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS

## Executar localmente

Requer Node.js e npm instalados.

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

## Estrutura

- `app/`: páginas, componentes e dados da aplicação
- `public/`: imagens e demais arquivos públicos
